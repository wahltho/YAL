# Yet Another Linda (YAL) Pilot Checklists

Version: see Settings window
Date: 2026-01-03

These checklists list pilot actions only. View changes and FMC page navigation are omitted.

<div style="page-break-after: always;"></div>

## Cold and Dark Startup

Checklist
- [ ] Battery ON
- [ ] Battery Cover CLOSED
- [ ] IF night: Dome Light ON (DIM)
- [ ] Emergency Lights ARMED
- [ ] Emergency Lights Cover CLOSED
- [ ] Position Lights STEADY
- [ ] IF GPU available and configured: Ground Power ON
- [ ] IF no GPU: Left Aft Fuel Pump ON
- [ ] IF no GPU: APU START
- [ ] IF no GPU: APU GEN 1/2 ON
- [ ] IF no GPU: APU Bleed ON
- [ ] IF no GPU: Isolation Valve OPEN
- [ ] IF no GPU: Packs AUTO
- [ ] IF no GPU: Trim Air and Recirc Fans ON
- [ ] IRS L/R NAV
- [ ] IRS Position ENTER (FMC POS INIT)
- [ ] IRS Position INITIALIZED

<div style="page-break-after: always;"></div>

## Cockpit Initialization

Checklist
- [ ] IF night: Dome Light ON
- [ ] IF configured: EFBs HIDDEN
- [ ] IF not ignoring brightness: Instrument Lights SET
- [ ] Window Heat ON
- [ ] No Smoking Signs ON
- [ ] IF configured: Lower DU Pages SET
- [ ] FMC RESET
- [ ] IF YANSH: SimBrief Flight Plan LOADED
- [ ] IF Auto Fueling: Fueling COMPLETE
- [ ] Flight Plan ACTIVATED in FMC
- [ ] FMC Route CONTINUOUS (discontinuities resolved)
- [ ] Takeoff Data (Flaps/CG/V Speeds) SET
- [ ] Transponder Code SET (if configured)
- [ ] Transponder STANDBY (if configured)
- [ ] Probe Heat OFF
- [ ] Seatbelt Signs OFF
- [ ] Position Lights STEADY
- [ ] Landing Lights OFF
- [ ] Runway Turnoff Lights OFF
- [ ] Taxi Lights OFF
- [ ] Autopilot Disconnect Bar RESET
- [ ] Flight Directors OFF
- [ ] MCP Altitude SET (Lower Airspace Alt or Cruise Alt)
- [ ] Bank Angle SET
- [ ] EFIS DATA ON
- [ ] Autobrake OFF
- [ ] Autopilot OFF
- [ ] IF engines not running: Fuel Levers CUTOFF
- [ ] Speedbrakes DOWN
- [ ] Master Caution RESET
- [ ] IF BetterPushback: Pushback Plan SET
- [ ] IF BetterPushback: Pushback START (if planned)

## Engine In-Flight Restart

Checklist
- [ ] Preconditions CHECKED (no fire, N1 rotation, no abnormal vibration, start envelope)
- [ ] Thrust Lever CLOSED (affected engine)
- [ ] Start Lever CUTOFF (affected engine)
- [ ] Start Switch FLT (windmill) or PACK OFF + Duct Pressure 30 PSI + Start Switch GRD (crossbleed)
- [ ] N2 >= 11 percent
- [ ] Start Lever IDLE (affected engine)
- [ ] EGT MONITORED (abort if no rise within 30 seconds)
- [ ] Engine RUNNING
- [ ] Generator ON (affected engine)
- [ ] Pack AUTO (affected side)
- [ ] Start Switch AUTO
- [ ] APU AS NEEDED
- [ ] Transponder TA/RA

<div style="page-break-after: always;"></div>
