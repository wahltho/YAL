# YAL 2.5 - X-Plane 11 Legacy Release

YAL 2.5 is the final YAL release compatible with X-Plane 11.

This version is provided as an unsupported legacy release. It receives no
updates or compatibility fixes. For X-Plane 12, use the latest official YAL
release from the official GitHub repository or YAL update channel.

Only releases published by the YAL copyright holder are official YAL
releases.
